# Portofolio Ramadhana

Akuntan dan Data Analis | Head Finance & Business Intelligence

Repository ini berisi halaman portofolio (`index.html`) dan empat notebook analisis data yang saya kerjakan dengan Python.

## Proyek analisis data

| Proyek | Ringkasan | Alat |
|---|---|---|
| [Uji A/B: dampak varian baru terhadap pendapatan 30 hari](notebooks/ab-testing-experimentation.ipynb) | 505 pengguna aplikasi langganan dibandingkan antara varian A dan B. Varian B menghasilkan rata-rata pendapatan 30 hari 480,67 dibanding 400,29 pada varian A (sekitar 20% lebih tinggi), signifikan secara statistik (t = -18,34; p < 0,05; Cohen's d = 1,63). | pandas, SciPy, Seaborn |
| [Segmentasi nasabah kartu kredit dengan K-Means](notebooks/customer-segmentation-kmeans.ipynb) | 641.914 transaksi kartu kredit dianalisis; 49.457 data lengkap dikelompokkan menjadi 6 segmen dengan RobustScaler, elbow method, K-Means, dan visualisasi PCA 2D. | pandas, scikit-learn, Matplotlib, Seaborn |
| [EDA dan statistik: profil demografi dan gaji karyawan](notebooks/eda-statistics.ipynb) | Eksplorasi 7.917 responden (umur, gaji, pekerjaan, pendidikan, riwayat stres) dengan analisis univariat, bivariat, dan multivariat. | pandas, SciPy, Matplotlib, Seaborn |
| [Pembersihan data: menyiapkan dataset untuk analisis](notebooks/data-collection-cleaning.ipynb) | Pengecekan tipe data, nilai kosong, outlier, dan duplikat. 699 baris kosong dibersihkan (7.917 menjadi 7.218 baris) dan 72 baris duplikat teridentifikasi. | pandas, NumPy, Seaborn |

Catatan: file data (CSV) tidak disertakan di repository ini.
