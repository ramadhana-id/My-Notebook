# 📊 Pengaruh Religiusitas, Lingkungan Sosial dan Pengetahuan Produk terhadap Keputusan Menabung di Bank Muamalat Jember

## Project Overview

Project ini merupakan analisis statistik menggunakan IBM SPSS Statistics untuk menganalisis hubungan dan pengaruh:

- X1 — Religiusitas
- X2 — Lingkungan Sosial
- X3 — Pengetahuan Produk
- Y — Keputusan Menabung

Objek penelitian: Bank Muamalat Jember.

## Dataset

Dataset yang digunakan berisi 315 responden dan mencakup:

- Jenis kelamin
- Usia
- Item X1.1–X1.5
- Total X1
- Item X2.1–X2.5
- Total X2
- Item X3.1–X3.5
- Total X3
- Item Y.1–Y.5
- Total Y

Data responden menggunakan label anonim seperti `Responden 1`, `Responden 2`, dan seterusnya.

## Analisis yang Dikerjakan

Analisis yang dilakukan menggunakan IBM SPSS Statistics meliputi:

1. Frequencies
2. Descriptive Statistics
3. Correlation Analysis
4. Reliability Analysis
5. Regression Analysis
6. Normality Test
7. One-Sample Kolmogorov-Smirnov Test
