# 🗄️ SQL Projects

Kumpulan project SQL untuk kebutuhan Data Analytics dan Business Intelligence.

Project di dalam folder ini berfokus pada pengolahan, analisis, dan eksplorasi data menggunakan SQL untuk menjawab kebutuhan bisnis.

## Projects

### 1. Sales Analysis with SQL

Analisis data penjualan menggunakan SQL untuk menghasilkan insight terkait:

- Monthly Sales Performance
- Shipment SLA Performance
- Top Product Revenue
- Sales Representative Performance
- Customer Segmentation

Project menggunakan query SQL dengan teknik:

- SELECT
- JOIN
- GROUP BY
- ORDER BY
- CASE WHEN
- Aggregation
- Subquery
- Date & Time Analysis
- Conditional Aggregation

📁 Folder project:
